# DomChat

React + TypeScript + Vite + Supabase веб-приложение для домового сообщества. Это самостоятельный сайт: он работает в обычном браузере и не требует MAX-бота, MAX SDK или токена бота.

## Возможности
- Регистрация/вход по email и паролю; обязательное согласие до регистрации, версия и полный текст записываются триггером БД.
- Домовой чат и личные сообщения в реальном времени.
- Добавление автомобилей и поиск по госномеру/марке/модели.
- Настройки видимости квартиры, подъезда, этажа и телефона (всё скрыто по умолчанию).
- Supabase RLS ограничивает доступ участниками одного дома.

## Запуск
1. Node.js 22+.
2. При необходимости скопировать .env.example в .env.local. Для подключённого проекта URL и публичный publishable key уже настроены в src/supabase.ts; переменные окружения могут переопределить их.
3. Для нового Supabase-проекта применить SQL-миграции из supabase/migrations/ в порядке имени. В подключённом проекте DomChat начальная миграция уже применена.
4. npm install; npm test; npm run build; npm run dev.

В Supabase Auth можно отключить подтверждение email, если нужен вход сразу после регистрации. Это не KYC и не проверка документов.

## Публикация
После однократного включения GitHub Pages в Settings → Pages с источником GitHub Actions приложение автоматически публикуется после успешных тестов и сборки. Адрес сайта: https://kinderdmitry.github.io/DomChat-MAX/.

## Приватность и эксплуатация
Телефон владельца не показывается в поиске автомобилей; предусмотрены личные сообщения. Текст согласия — технический проект, не юридическое заключение: перед публичным запуском добавьте реквизиты юридического оператора, сроки хранения и контакты, проверьте документ с юристом, настройте резервное копирование и rate limits. Не используйте реальные персональные данные до этого.

## Подключение Supabase
Клиент использует публичный publishable key (sb_publishable_...) и URL проекта. Такой ключ предназначен для браузерного приложения; безопасность данных обеспечивается RLS и политиками БД. Никогда не помещайте service_role или secret key во frontend, .env с коммитом или GitHub Pages.
