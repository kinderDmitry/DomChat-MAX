# DomChat MAX

React + TypeScript + Vite + Supabase приложение для домового сообщества и MAX Mini App.

## Первый этап
- Регистрация/вход по email и паролю; обязательное согласие до регистрации, версия и полный текст записываются триггером БД.
- Домовой чат и личные сообщения в реальном времени.
- Добавление автомобилей и поиск по госномеру/марке/модели.
- Настройки видимости квартиры, подъезда, этажа и телефона (всё скрыто по умолчанию).
- Supabase RLS ограничивает доступ участниками одного дома.
- MAX Bridge подключён официальным CDN, вызывается WebApp.ready().

## Запуск
1. Node.js 22+.
2. Скопировать .env.example в .env.local и заполнить VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY.
3. Применить supabase/migrations/202611170001_initial_schema.sql через Supabase SQL Editor.
4. npm install; npm test; npm run build; npm run dev.

В Supabase Auth можно отключить подтверждение email, если нужен вход сразу после регистрации. Это не KYC и не проверка документов.

## MAX
Mini App запускается через чат-бота MAX. После публикации на HTTPS нужно указать URL приложения в настройках бота на платформе MAX для партнёров. До авторизации через MAX сервер должен проверять подпись window.WebApp.initData токеном бота. Токен нельзя хранить во frontend или Git. Сам бот и его секреты ещё нужно создать/настроить.

## Приватность и публикация
Телефон владельца не показывается в поиске автомобилей; предусмотрены личные сообщения. Текст согласия — технический проект, не юридическое заключение: перед публичным запуском добавьте реквизиты юридического оператора, сроки хранения и контакты, проверьте документ с юристом, настройте резервное копирование, rate limits и серверную проверку MAX initData. Не используйте реальные персональные данные до этого.
